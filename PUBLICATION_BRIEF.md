# Publication brief

## Recommendation

Lead with: **“Seven local models, three real repository tasks, one full solve.”**

The strongest supported story is not that one model is universally best. Ten outcomes changed the candidate snapshot, but only one passed every frozen gate. Ten normal completions still failed. Ornith 1.5 9B was the only model to earn a full PASS, on C10.

## Evidence

- 21 valid official model-task outcomes.
- C08: 0/7 PASS.
- C09: 0/7 PASS.
- C10: 1/7 PASS, earned by Ornith 1.5 9B.
- 10/21 outcomes reached the frozen 1,800-second budget.
- Every model ran locally with network disabled and a four-tool candidate surface.
- Round 2 received an independent fresh-context freeze audit PASS.

## Material caveat

These are 21 observed outcomes from three tasks in one repository on one local machine. They are not a population estimate or a general coding leaderboard.

## Recommended sequence

1. Owner reviews the data tables, graphics, and X drafts.
2. A fresh independent publication reviewer checks claims, visuals, and leakage.
3. Correct publication-package issues only; never rewrite frozen benchmark evidence.
4. Publish the methodology and limitations with the result graphics.
5. Begin D02 design only after the public package is frozen.
